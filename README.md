## ✨ Características Principales

* **Catálogo Dinámico:** Carga de productos en tiempo real desde el backend.
* **Filtros por Categoría:** Navegación fluida entre los distintos tipos de velas artesanales.
* **Carrito de Compras:** Gestión de artículos con persistencia local (`LocalStorage`).
* **Pasarela de Pagos:** Integración segura con **Mercado Pago** para procesar transacciones.
* **Registro de Órdenes:** Almacenamiento automático de pedidos y estados en **PostgreSQL (Supabase)**.
* **Diseño Responsivo:** Interfaz adaptada para dispositivos móviles y de escritorio con un estilo elegante.

---

## 🛠️ Tecnologías Utilizadas

### Frontend
* **HTML5 / CSS3:** Estructura semántica y diseño visual minimalista.
* **JavaScript (Vanilla):** Lógica del cliente, consumo de API y manipulación del DOM.
* **GitHub Pages:** Despliegue continuo del cliente estático.

### Backend y Base de Datos
* **Node.js & Express:** Servidor REST API para la gestión de peticiones y pasarela de pagos.
* **Mercado Pago SDK:** Procesamiento de preferencias de pago seguras.
* **PostgreSQL (Supabase):** Base de datos relacional para control de órdenes.
* **Render:** Despliegue del servidor backend.
